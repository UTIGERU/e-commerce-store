# E-commerce Store

A modern, responsive e-commerce website built with HTML, CSS, and JavaScript.

## Features

- Product catalog with grid layout
- Shopping cart functionality
- Responsive design for mobile devices
- Local storage for cart persistence
- Smooth animations and transitions

## Setup Instructions

1. Create a new folder in VS Code
2. Add the provided files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Open `index.html` in your browser or use a live server extension

## Customization

- Add real product images in the `images/` folder
- Modify product data in `script.js`
- Update colors and styling in `style.css`
- Add more features like product categories, search, etc.

## Browser Support

Works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
